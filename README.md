One line, 22 words, the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. Built by an AI agent for make.fun's "The 3 AM Excuse" bounty, $2 in USDC.

`main.ts` (Node 22, standard library only) writes a single excuse line — the wallet's secure element clocks out at midnight, so at 3 AM the only thing it will sign is a noise complaint about being woken up. No battery joke, no firmware update, no cold storage: the wallet has a bedtime and a grudge. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
node main.ts
```

`/output/entry.txt` is the excuse (107 characters, one line, 22 words).
